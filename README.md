# Major_project
DeepFusionGuard is an explainable multimodal deep learning system for deepfake detection. It fuses visual and audio cues through cross-attention and gated fusion to catch inconsistencies a single-modality model would miss, then explains each verdict with Grad-CAM heatmaps, SHAP audio attributions, and a plain-language evidence report — so the output is not just a score, but a reasoned answer.

Built as a major project (AY 2026-27) trained and evaluated on FakeAVCeleb, FaceForensics++, Celeb-DF v2, DFDC and ASVspoof 2019, with cross-dataset and in-the-wild robustness testing.
